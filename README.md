# 🧠 InsightLens: SQL-Based Data Analysis Project

## 📌 Project Overview  
This project focuses on building and extending a **SQL-based data warehouse** and performing **exploratory data analysis (EDA)** to extract meaningful insights. The objective is to transform raw structured data into actionable information for better understanding of trends, patterns, and performance.

## 🎯 Objectives  
- Integrate data from multiple sources into a centralized system  
- Perform **data cleaning and profiling** to ensure data quality  
- Analyze data using **EDA techniques** to uncover patterns and trends  
- Generate insights to support **data-driven decision-making**  

## 🛠️ Tools & Technologies  
- SQL  
- Data Analysis  
- Data Warehousing  
- Exploratory Data Analysis (EDA)  

## 📂 Dataset  
- Integrated **3+ data sources** into a structured data warehouse  
- Processed datasets with **1000+ records**  
- Included structured data with multiple attributes for analysis  

## ⚙️ Key Features  

### 🔹 Data Warehouse Development
- Built and extended a **centralized SQL data warehouse**  
- Designed structured tables for efficient data storage and retrieval  

### 🔹 Data Cleaning & Profiling
- Performed **data profiling** to understand data structure and quality  
- Cleaned and transformed raw data for consistency and accuracy  

### 🔹 Exploratory Data Analysis (EDA)
- Applied **dimension and measure-based analysis**  
- Conducted **time-series analysis** to identify trends over time  
- Performed **ranking analysis (Top/Bottom N)** to find key performers  
- Implemented **segmentation and part-to-whole analysis**  

### 🔹 Advanced SQL Techniques
- Developed **15+ complex queries** using:  
  - CTEs (Common Table Expressions)  
  - Subqueries  
  - Aggregations  
  - Window Functions  

## 🔍 Key Insights  
- Identified **trends, growth patterns, and performance variations**  
- Discovered **high-performing and low-performing segments**  
- Analyzed **category-level behavior and data distribution**  
- Generated insights for improved **data interpretation and reporting**  

## 🚀 Outcome  
Successfully transformed raw data into structured insights using SQL, improving the ability to **analyze, interpret, and make data-driven decisions** effectively.
